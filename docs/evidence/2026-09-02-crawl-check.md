# Crawl evidence: real AI user-agents against a clean WordPress 7.1

Date: 2026-09-02. Plugin: WP Agent Support Layer 1.0.0 (distributable zip built by `composer run build`).
Environment: Docker, `php:7.4-apache` and `php:8.3-apache` with mod_rewrite, MySQL 8.0, clean WordPress 7.1
installed by `bin/smoke-docker.sh`, default settings (posts and pages enabled, `search=yes, ai-input=yes, ai-train=no`).

This is the evidence for action 8 of the requirements document ("pruebas de rastreo simulando crawlers de IA
reales"): each request below was made with `curl` and the user-agent string each vendor documents, from
outside the container, so it reflects exactly what the crawler would receive from the origin.
