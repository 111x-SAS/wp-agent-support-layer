# Smoke evidence: 1.0.2 review fixes on a clean WordPress 7.1

Date: 2026-09-02. Plugin: WP Agent Support Layer 1.0.2 (distributable zip built with the same steps as
`.github/workflows/release.yml`). Environment: Docker, `php:7.4-apache` and `php:8.3-apache` with mod_rewrite,
MySQL 8.0, clean WordPress 7.1 installed by `bin/smoke-docker.sh`, default settings.

This is the evidence for tasks 15.1 and 15.2 of the OpenSpec change `fix-review-findings`: activation,
generation, Markdown delivery, discovery files, storage protection, **static front page Markdown URL**
(`/?wpasl=md` and `/.md`, finding 2), **no `X-Robots-Tag` and `nosniff` on Markdown** (finding 10),
**diagnostics executed in batches** with the time budget forced down to 2 s so the split is visible
(finding 5; every admin request stays far below Cloudflare's 100 s limit), the real user-agent crawl check,
and a clean uninstall.

Automated suites run before this smoke test on the same commit: PHPUnit 226 tests (single site, 3 skipped as
multisite-only) and 226 tests (multisite), PHPCS clean.
